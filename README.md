# WAD

## Course Information

- **Title:** Web Application Development
- **Code:** CS-324
- **Instructor:** Dr. Rabeeh Ayaz Abbasi

## Description

It's about the web. It aims to impart the fundamental knowledge required to understand the relationship among webpages, the web browser, and the server. It explores how HTML, CSS, and JavaScript work together to create webpages.

In view of the prevailing AI revolution, it also extends to the understanding of certain techniques which, when employed, allow us to use AI efficiently in web development.
